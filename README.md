# 💈 BARBERCLUB - Sistema de Gestão por Assinatura

Bem-vindo ao repositório do **Barberclub**, um projeto desenvolvido para a disciplina de Projeto Integrador. 

O Barberclub é um sistema focado na fidelização de clientes de barbearias através de planos de assinatura (receita recorrente), gerenciado pela tecnologia **SÍRUS**.

## 🚀 Status do Projeto
Em desenvolvimento (Fase de Prototipação).

## 🛠️ Tecnologias Utilizadas
* **Front-end:** HTML5, CSS3 (com Glassmorphism), Tailwind CSS.
* **Lógica / Simulação de Banco de Dados:** JavaScript (manipulando `localStorage` para simular as transações de Front-end e Back-end nesta primeira fase).
* **Gestão e Versionamento:** Git e GitHub (com migração futura para Azure DevOps).

## 📋 Funcionalidades Atuais (Protótipo)
- [x] **Landing Page:** Vitrine da barbearia com apresentação dos planos.
- [x] **Planos de Assinatura:** Opções *Executive Club* e *Legendary Club*.
- [x] **Checkout / Adesão:** Captura de dados do cliente e registro da assinatura.
- [x] **Banco de Dados Local:** Salvamento e persistência das assinaturas no navegador (`barberclub_db`).
- [ ] **Painel SÍRUS (Admin):** Área do administrador para gestão de clientes e caixa (Em desenvolvimento).

## 💻 Como rodar este projeto?
Como esta é a versão de prototipagem focada no Front-end, você não precisa instalar nenhum servidor complexo.
